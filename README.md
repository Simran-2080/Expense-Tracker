# Expense Tracker 
https://simran-2080.github.io/Expense-Tracker/

A simple, interactive Expense Tracker built with **HTML, CSS, and Vanilla JavaScript** to practise JavaScript fundamentals through real-world implementation.

## About the Project

The main purpose of this project is to move beyond learning JavaScript concepts theoretically and understand how to apply them while building a functional application.

Instead of only studying individual methods and syntax, I built this project to practise working with data, handling user interactions, manipulating the DOM, and implementing features that work together in a real application.

This project is part of my journey to strengthen my JavaScript fundamentals through hands-on practice.

## Features

- **Add Expenses:** Add an expense with a name, amount, and category.
- **Delete Expenses:** Remove individual expenses from the list.
- **Category Filtering:** Filter expenses by category.
- **Search Expenses:** Search for expenses by name.
- **Total Expenses:** Calculate the total amount of all expenses.
- **Category-wise Summary:** View separate totals for Food, Travel, and Other expenses.
- **Input Validation:** Prevent empty expense names and invalid or non-positive amounts.
- **Dynamic Rendering:** Update the displayed expense list when data changes or filters are applied.

## How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Add expenses and try the search, category filters, and summary calculations.
